Data Methodology

This dashboard aggregates startup financial and operational data from Latvian companies (2021-2024). For each metric (turnover, profit, employees, budget payments), we identify the most recent non-null value as "current" and the previous non-null value for year-over-year comparison. Missing values are excluded from calculations rather than treated as zero.

If you want your startup to be listed in the database, please submit information via this form, and we will add it (if the company adheres to Startin.LV's outlook on what is a startup).
